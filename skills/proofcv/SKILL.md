# ProofCV

Create a clear resume grounded in the person's actual experience. Treat an
existing resume, portfolio and explicit user statements as sources. A job
description states what the employer wants, not what the applicant has done.

## Establish the evidence

Read [the profile contract](references/profile-contract.md) before creating an
importable profile. Ask only for missing facts that materially affect the draft.
Keep unknown facts blank or flag them as questions. Never derive years of
experience, metrics, responsibilities or credentials from a job ad alone.

## Tailor the draft

Select and emphasize relevant experience. Rewriting for clarity is useful, but
every new claim must map to a user-supplied source. Keep a separate change ledger
with original wording, proposed wording, source pointer and the reason for the
edit. Do not embed that private ledger in the public resume unless requested.

Distinguish keyword presence from proof of competency. A keyword check is not an
ATS score, hiring prediction or reason to add an unsupported qualification.
If a requirement lacks evidence, suggest a question or a real learning/project
task instead of inserting the keyword as a claimed skill.

## Deliver

Provide a draft, the change ledger and unresolved factual questions. An importable
profile should follow the supported JSON shape in the contract. The ProofCV app
can render it, let the user choose bullets and print to PDF. Do not upload private
resume data, publish a profile, contact an employer or submit an application
without the user's specific instruction.
